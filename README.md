# Martha Play Updates

This public repository distributes update manifests for Martha Play.

- APK files are published as immutable GitHub Release assets and are never committed to Git.
- `staging/latest.json` is published and validated before any release is promoted to `stable/latest.json`.
- This repository does not contain the Martha Play source code.
- Manifests and release assets are public, unauthenticated HTTPS resources and contain no credentials.
